# 文書の言語

README、仕様、計画、開発・検証記録、素材の案内、プロンプト保存の案内は英語を標準とします。各ページ冒頭のリンクで日本語版を開けます。

翻訳前からあった日本語文書は、同じ場所の `.ja.md` ファイルに保持しています。本文の文言は変更せず、言語切替と日本語版へのリンクを追加しています。既存の英語概要に対応する日本語の [README](../README.ja.md) と [ENS UI設計](../specs/ENS_UI_DESIGN.ja.md) も用意しました。原文を保持したページには「原文保存版」と表示しています。更新した発行コマンド例は英語版を参照してください。過去の文書には当時の判断や制約を残しています。現在の要件は [最新仕様](../specs/SPEC.ja.md) を参照してください。

コード生成には英語の [OpenAPI定義](../specs/openapi.ja.yaml) を使います。[openapi.ja.yaml](../specs/openapi.ja.yaml) は日本語の説明を保持するスナップショットです。APIスキーマ、サンプル値、記録された名前は変更していません。

自動保存したプロンプトJSON、提供された会話原文、`.txt` の画像生成報告、検証の生データは原文のまま保持しています。これらは書き換える説明文書ではなく、出典となる記録です。英語の案内には保存方法と確認範囲を記載しています。英語にした引用は翻訳と明記しています。アプリの日英切替と提供画像は変更していません。

言語ペアと原文ハッシュは [languages.json](languages.json) に記録しています。日本語本文の保持、双方向の言語リンク、ローカル文書へのリンクを確認するには、リポジトリのルートで次を実行します。

```sh
python3 scripts/verify_documentation.py
```

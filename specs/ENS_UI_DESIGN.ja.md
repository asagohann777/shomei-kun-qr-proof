# ENS検索UIの改訂

ユーザーは、ホームのQRボタンと同じ形で薄い青色の検索ボタンと、分かりにくかった検索画面の再設計を求めた。白・紺・青の配色と、既存のカード画像・背景を維持する。

配色は白 #ffffff、紺 #102958、操作ボタンの青 #086bdc、淡いボタン色 #dcecff、境界線 #bdd8f4、補助文字 #536782。既存の日本語サンセリフ体を維持する。見出し24px、カード名17px、本文14px、補助文字12px。

ホームは同じ大きさの丸みのあるボタンを縦に並べ、濃いQRボタンを先に、淡いENS検索ボタンを次に置く。検索画面は小さいフローヘッダー、短い見出し、白い入力領域を使う。解決した名前・ウォレット情報と、カード画像付きの縦一覧を分ける。入力ラベルと結果は左揃え。各行に既存カード画像、カードID、登録名、登録記録を開く操作を置く。

    ENS名・アドレスで探す
    [ENS名またはアドレス    ]
    [        検索          ]
    shomeikun.eth / ウォレット詳細
    ウォレットに登録されているカード
    [カード画像] 証明一郎 / TC-001
                 登録記録を見る

汎用的なダッシュボードの枠ではなく、実際の野球カード素材を使う。結果は白い領域にまとめ、行間を区切る。長い技術説明とモックの説明は折りたたみ式のヘルプへ移し、検索欄と結果の間には置かない。モックではサンプルデータである表示を残す。

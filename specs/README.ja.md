# 仕様書の入口

現在の動作は次の資料にまとめている。

| 資料 | 内容 |
| --- | --- |
| [SPEC.md](SPEC.md) | サービスの範囲、画面、機能、受け入れ条件 |
| [ARCHITECTURE.md](ARCHITECTURE.md) | 構成、データの流れ、権限、モード |
| [DEMO.md](DEMO.md) | スマホ・iPadでの実演手順 |
| [CAMERA_SCAN.md](CAMERA_SCAN.md) | QR受付形式とカメラの停止・再開 |
| [openapi.yaml](openapi.yaml) | APIのリクエスト・応答・エラー |
| [CURVEGRID_INTEGRATION_RUNBOOK.md](CURVEGRID_INTEGRATION_RUNBOOK.md) | 接続設定、ビルド、検証 |
| [OpenSpec](../openspec/specs/curvegrid-registration-backend/spec.md) | 要件ごとの確認シナリオ |

開発経緯と試験結果は [HACKATHON_CHANGES.md](HACKATHON_CHANGES.md)、既存成果は [PRE_EXISTING_WORK.md](PRE_EXISTING_WORK.md) を参照する。`*_PLAN.md`、`*_REPORT.md`、`*_IMPLEMENTATION.md`、`BACKEND_DESIGN.md` は当時の計画・設計・検証記録として残す。

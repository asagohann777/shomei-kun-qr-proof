# ENS search UI revision

The user asked for a pale-blue home button matching the QR button, and a replacement for the confusing search screen. Keep the white/navy/blue card-app identity and existing illustrated backgrounds.

Palette: white #ffffff, navy #102958, action blue #086bdc, pale button blue #dcecff, border blue #bdd8f4, secondary text #536782. Retain the application's Japanese sans-serif stack. Headings 24px, card title 17px, body 14px, secondary text 12px.

Home: stack equal-sized pill buttons, saturated QR first and pale ENS second. Search: use the smaller flow header, a short title, and one white input area. Results: separate the resolved name/wallet from a vertical list of illustrated trading-card rows. Left-align form labels and results. Each row shows the existing card artwork, card ID, registered nickname and an explicit action to view the registration record.

Review against the brief: retain the actual baseball-card artwork rather than generic dashboard boxes. Use a continuous white results area with dividers between cards. Move lengthy technical and mock instructions into expandable help; never put them between the query and its results. Keep the synthetic-data notice visible in mock mode.
